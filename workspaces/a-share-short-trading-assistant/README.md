# A 股短线交易研究助手（DSHA 工作区）

这是放进 DSHA「A 股短线交易助手」工作区的 Markdown 指令，不是新的行情插件。它负责组织现有插件，分别执行盘前准备、盘中跟踪和盘后复盘，并遵守用户的资金—筹码—板块迁移理念。

## 使用方式

1. 在 DSHA 建立一个名为「A 股短线交易助手」的工作区。
2. 将 `AGENT.md` 的全部内容复制到工作区指令/Markdown 文件中。
3. 在插件管理页分别启用需要的工具。此工作区不会自动安装插件，也不能调用未启用的工具。
4. 首次对话可发送：`先检查当前可用的插件工具，并告诉我盘前、盘中、复盘分别会调用哪些工具；不要假设我当前持仓。`
5. 后续可发送：`做今天盘前计划`、`根据这张截图做盘中更新`、`复盘今天市场和我的计划`，并补充关注板块/个股、行情截图或实际成交记录。

## 仓库中的插件目录

- `a-share-market-data`：行情、区间统计、热度与筹码数据。
- `global-macro-assistant`：全球宏观观察。
- `industry-opportunity`：行业事件与机会线索。
- `industry-company-quality`：产业链和公司质地研究。
- `short-term-position-manager`：持仓快照、风险预算与仓位计划。

若 DSHA 中已启用国内宏观插件，也可由工作区按指令调用；助手应先确认工具实际存在。仓库目录不是插件状态证明。

## 输出和安全边界

- 以概要输出串联多个插件；用户单独研究某公司/行业/持仓时，再请求详细模式。
- 插件结果要保留来源、观测日期、数据频率、覆盖范围和缺失项。
- 筹码分布、供应商资金流和新闻扫描均有各自的口径限制，详见对应插件 README。
- 所有仓位结果都是计划，不连接券商、不下单。持仓截图先复核再由用户确认导入。
- 盘前预案、盘中修订和盘后复盘分别追加保存，不覆盖旧判断。

## 文件

- `AGENT.md`：完整工作区角色、交易理念、工具编排、三阶段流程、输出规则与日志模板。DSHA 若要求固定文件名，可直接使用此文件内容。
- `WORKSPACE.md`：与 `AGENT.md` 内容一致的工作区版备份。
