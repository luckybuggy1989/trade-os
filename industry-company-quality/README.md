# 行业与公司质地研究 · DSHA 插件 0.1.0

输入行业名称或上市公司，生成有证据边界的产业链和公司研究上下文。行业研究覆盖上下游、关键节点、价值分配、供需周期、政策/技术变化与机会轮动触发点；公司研究覆盖链路环节、财务质量、竞争优势、客户/供应商关系、定价权与议价权、治理风险和反证。

插件为两种模式：

- `summary` 概要模式：适合多插件共同工作，返回主要判断上下文、证据覆盖和关键缺口。
- `detailed` 详细模式：用于单独研究，逐项显示产业链、财务比率、来源证据、竞争解释、轮动触发和反证清单。

## 分析逻辑

### 行业与产业

1. 定义行业边界、产品/服务、地区、分类和替代品，避免用主题概念替代真实市场。
2. 拆成上游资源/设备/零部件、中游工艺/制造/平台、下游渠道/应用；记录投入产出、成本占比、认证周期、库存、交付和账期。
3. 找价值链利润池和约束点：谁掌握定价、稀缺供给、标准、客户入口、关键工艺或渠道。
4. 观察需求、产能、利用率、在建项目、库存、价格、成本曲线、订单交期、资本开支及其滞后关系。
5. 周期阶段作为可推翻的假设，至少用两类独立指标确认；不从单一价格或新闻判定复苏/过剩。
6. 机会轮动点按“先行指标 → 产业环节传导 → 订单/出货/利润兑现 → 公司对应产品收入 → 反证”表示。每个触发点注明频率、观察窗口、发布日期和失效条件。
7. 建基准/上行/下行情景，列清楚关键变量和需要什么新事实推翻当前判断。

### 个股质地与话语权

- **链路位置**：核心产品、工序/服务、收入与利润贡献、客户/供应商关系、替代品、需求来源。行业归类标签不等于实际主营受益。
- **经营质量**：收入/利润增长、毛利率/营业利润率、经营现金流与净利润、自由现金流、资本开支、应收/库存、负债和研发投入。区分审计数据、公司口径和第三方估算。
- **竞争优势**：成本、性能/良率、认证、切换成本、渠道、规模、有效专利和商业化验证。专利数量、客户名单或订单框架都不能单独证明护城河。
- **话语权**：价格调整机制、成本传导能力、毛利率跨周期表现、客户/供应商集中度、账期、替代供应、客户认证周期和稀缺供给。客户集中可能同时意味着稳定订单和依赖风险。
- **治理与风险**：审计意见、交易所问询、处罚、关联交易、质押、商誉、资本配置和承诺兑现。

不输出未经校准的“公司质地总分”或市场份额。市场份额必须有产品、地域、期间和可比口径；ROIC需要平均投入资本数据，缺少时不以ROE替代。

## 可信数据来源

| 来源 | 可核对内容 | 重要口径限制 |
|---|---|---|
| [巨潮资讯](https://www.cninfo.com.cn/)及[上交所上市公司门户](https://one.sse.com.cn/list/) | 年报、季报、临时公告、业绩说明会 | 法定披露优先；公司管理层解释仍需与审计报表、现金流和后续兑现互证。 |
| [国家统计局数据查询](https://data.stats.gov.cn/)与[数据发布](https://www.stats.gov.cn/sj/zxfb/) | 工业产量、价格、库存、利润、投资和宏观需求 | 统计分类、样本范围、初值/修订及发布滞后需保留；规模以上口径不代表全行业。 |
| [工信部行业统计分析](https://www.miit.gov.cn/gxsj/tjfx/index.html) | 电子、汽车、软件、原材料等行业运行 | 子行业发布频率、产品定义不同；产量不等于销量或终端需求。 |
| [海关统计数据查询](https://online.customs.gov.cn/ocportal/mySearch/) | 进出口商品数量、金额和贸易流向 | HS 商品编码与上市公司产业分类不一一对应；金额/数量的单位需统一。 |
| [国家知识产权局专利检索与分析](https://pss-system.cponline.cnipa.gov.cn/conventionalSearch) | 专利全文、权利状态、同族与引用线索 | 检索结果需核实权利要求、有效性、归属和产品收入；专利数量不等于技术壁垒。 |
| [国家发展改革委](https://www.ndrc.gov.cn/)及[证监会](https://www.csrc.gov.cn/) | 产业政策、项目制度、监管规则、处罚和许可 | 区分征求意见、正式文件、项目落地和实际资金/订单。 |

这些来源大多是正式网页或查询系统，并没有一个可免费、统一且稳定覆盖全行业和公司质地的数据API。首版不冒充自动爬取全部行业数据；固定工具维护来源目录、本地证据链和可复算财务比率。对实时产业判断，助手须以可访问的一手原始材料为据，再把关键事实通过证据工具保存。

## 固定工具

- `industry_source_catalog`：列出一手来源和各自限制。
- `industry_chain_report(industry,mode,asOf,since)`：按输入行业生成研究上下文、读取已保存产业链图和证据；详细模式附分析模板、周期/轮动框架和数据缺口。
- `industry_chain_map_save(industry,asOf,nodes,links,sourceUrls)`：保存上游/中游/下游/赋能/替代节点与证据链接。
- `industry_evidence_save(...)`：保存行业或公司的数据点、事件、经营事实、反证与原始来源。每条记录包括期间、发布日期、来源等级和限制。
- `industry_evidence_search(industry,company,since)`：查本机已经核验和保存的证据。
- `company_quality_report(industry,company,code,financials,mode,asOf)`：读取公司证据；可传入多期财务数据后确定性计算同比、CAGR、毛利率、利润率、经营现金流/净利润、自由现金流、负债率、ROE粗略口径、研发强度和营运资金比例。
- `industry_company_status`：查看本地行业图、证据和公司财务数据覆盖。

财务数据输入使用同一币种和单位，期间填 `YYYY` 或 `YYYY-Q1` 至 `YYYY-Q4`；`financialSourceUrl` 必须指向核对过的报表。工具计算的是比率，不代替会计口径复核。季度数据的同比仅在有同季度上年数据时计算；现金流/净利润基期为零或负时不作强结论。

## 手机安装和使用

Node.js 24+，数据保存在本机 `~/.local/share/dsh-industry-company-quality/industry-company-quality.sqlite`。在 DSHA 插件页从 GitHub 仓库 `luckybuggy1989/trade-os` 选择 `industry-company-quality` 子目录。

建议先调用 `industry_source_catalog`，然后用 `industry_chain_report` 输入行业名称。核验资料后调用 `industry_chain_map_save` 和 `industry_evidence_save` 保存证据；分析公司时调用 `company_quality_report`，传入经核实的年报数据或读取已有数据。概要模式适合跨插件传递，详细模式适合单独深挖。

插件不会连接证券账户、下单或推断用户持仓；来源覆盖不足时保留“未知”，不补造事实。
