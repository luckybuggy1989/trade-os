# DSHA 组合策略引擎 0.1.0

对主助手传入的资金证据和用户确认风险参数执行确定性预算闸门：市场总暴露 → 板块预算 → 个股固定 R。它不采集行情，不连接券商，也不下单。与持仓管理插件分工：该插件计算候选交易的预算上限和股数；持仓插件负责持仓快照、导入和组合调整建议。一个候选的计划数量不得超过本插件给出的数量。

## 工具

- `portfolio_strategy_profile_set`：确认单笔固定 R、组合开放风险上限、市场/板块/个股暴露上限、往返成本估计、最多并行标的和规则版本。没有内置个性化比例。
- `portfolio_budget_start`：传入六层资金证据、资金/趋势状态覆盖情况、账户权益/现金、当前市场暴露/开放风险与每个板块预算，建立当日预算上下文。来源需 HTTPS，六层各需至少一条非假设证据；未知或冲突直接阻断。板块预算总和不能超过市场上限。
- `portfolio_size_trade`：仅按固定 R 计算沪深A股100股整手数量，同时受现金、市场、板块、单股、并行标的上限约束；同一上下文内预留资金/暴露/风险，防止多标的重复占用。
- `portfolio_strategy_history` / `portfolio_strategy_status`：查看历史预算、分配和规则配置。

## 策略闸门

V1只允许 `S2_PULLBACK`：结构输入要求 H2>H1、L2>L1，且数据截止日完整K线收盘价高于 H2。未完成K线不触发。S1启动试仓、S3趋势延续、S4衰竭防守只标记为研究/模拟，不能得出执行数量。策略输出仍是 `PLAN_ONLY`，用户保留最终交易决定。

每股预估风险 = 入场价 − 止损价 + 入场价 × 用户设置的往返成本比例；股数按可用风险金额、现金、市场/板块/个股预算中最紧约束向下取整到100股。往返成本比例是估算参数，用户应按粤开交割单成本校准。跳空、跌停、停牌和滑点可能造成超预算损失。

## 与规划文档的差距

- 六层资金状态与市场仓位上限由主 Agent 基于来源数据判断后传入；插件要求证据覆盖但不把多个渠道硬加成单一“净流入”。
- 初始市场风险矩阵必须由用户配置/确认；文档中的矩阵示例没有被当成默认规则或回测结论。
- 尚不含状态滞回、连续亏损暂停规则、S1/S3/S4、港股交易单位、券商账户同步、交互图表、历史回测或监控通知。
