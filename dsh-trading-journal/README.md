# DSHA 交易日志与复盘插件 0.1.0

把研究计划、用户确认的实际成交、FIFO持仓快照和复盘记录追加保存在手机本机 SQLite。此插件不连接粤开证券或其他券商，不会自动获取/补齐成交数据，不包含下单接口。

## 工具

- `journal_record_plan`：追加计划，保存策略/规则版本、来源快照、动作、风险预算字段、触发与退出条件。只有明确确认后记录；记录仍是 `PLAN_ONLY`。
- `journal_record_fill`：只记录用户提供且明确确认的成交。要求唯一成交ID、证券、方向、日期时间、数量、价格、费用和来源类型；重复成交ID拒绝写入。
- `journal_record_review`：追加盘前、盘中、盘后、周度或单笔交易复盘。
- `journal_snapshot`：从日志成交回放 A 股 FIFO 持仓、可卖数量和已实现盈亏，按快照日期应用同日买入不可卖的 T+1 限制。
- `journal_history`：读取计划、复盘或快照历史。

## 当前范围与口径

首版成交流水只支持沪深 A 股。买入按100股整数手校验；卖出允许不足整手的尾数用于清仓。成本采用 FIFO，买入费用按成交股数比例分配，卖出费用从卖出金额扣除。无公司行动、转托管、红利税、融资融券、港股或复杂税费处理；费用正确性取决于用户输入，与券商交割单对账后使用。

日志数据库：`~/.local/share/dsh-trading-journal/trading-journal.sqlite`。本机数据不会由插件上传。用户应先从券商导出历史成交并核对后再录入；不能把截图识别草稿当成交。

Node.js 24+，DSHA 0.2.2 插件包。检查命令：`npm test`。未在小米 14 Pro 实机验证。
