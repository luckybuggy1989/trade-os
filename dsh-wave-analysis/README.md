# DSHA 波浪分析插件 0.1.0

独立的确定性计算插件。它消费调用方提供的多周期 OHLC 数据，生成百分比反转枢轴、校验基础推动浪规则、计算明确锚点的斐波那契价格/时间水平，并追加保存人工可复核的浪型快照。

## 工具

- `wave_detect_pivots`：百分比反转枢轴，输出拐点发生时间和确认时间；末端极值标为未确认。
- `wave_validate_impulse`：检查 0–5 推动浪的基础越界、3浪最短和4浪重叠规则。
- `wave_project_price`：根据显式价格锚点计算回撤/扩展水平。
- `wave_project_time`：按交易K线或日历日计算候选时间窗口，强制区分单位。
- `wave_right_side_structure`：检查 H1-L1-H2-L2 是否满足 H2>H1、L2>L1；突破还需后续完整 K 线收盘确认。
- `wave_snapshot_save` / `wave_snapshot_history`：浪型快照追加保存，不覆盖历史判断。

## 与行情插件配合

先由 A 股行情插件调用 `ashare_kline_fetch` 或 `ashare_kline_read` 获取所需周期K线，再将 OHLC、数据截止时间、可得时间、行情来源和版本交给本插件。插件不联网拉行情，不调用其他插件，也不会把后续确认的拐点回填成过去时点已知信息。A/H 市场字段只标记数据来源市场；当前比例与推动浪规则工具不实现港股交易单位或市场制度处理。

## 方法边界

枢轴默认 5% 百分比反转、最少间隔 2 根K线；均为可调整的研究参数，不是优化或校准结果。`wave_validate_impulse` 只检查基础规则，延伸浪、复杂调整和对角线需要人工审阅。时空比例是候选观察窗口，不是预测概率或反转保证。插件没有交互式K线图/拖拽标注UI；人工浪型可作为点位及主备方案输入保存。

设备本地 SQLite：`~/.local/share/dsh-wave-analysis/wave-analysis.sqlite`。数据、插件执行逻辑和来源应按设备同UID权限理解；不存券商凭证。

Node.js 24+，DSHA 0.2.2 插件包。检查命令：`npm test`。未在小米 14 Pro 实机验证。
